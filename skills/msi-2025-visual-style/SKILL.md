# MSI 2025 视觉转译

直接制作用户指定物料。先确认必须文案、品牌/主体、比例、用途与交付形式；低风险概念可自行补足，清楚标明虚构内容。缺失项只有会改变结果时才追问。

先读 [风格规则](references/style-guide.md)、[物料适配](references/adaptation.md) 和 [证据索引](references/sources.json)。这些是从公开项目归纳的复现建议，不是官方品牌手册。离线仍可按规则制作；在线核对原图通过索引原站，包内的赛事原作参考与原创生成概念已分开标注，来源和使用范围见 [SOURCE_NOTICE.md](SOURCE_NOTICE.md)。

把必读信息先排成字块和独立净区。近黑承载空间、偏白宽重紧排无衬线承担标题、信号红承担长尖电性图形；紫色手绘箭头/环线少量使用。红底黑图可反转。不要把所有字变窄高或切碎。中文用粗黑体紧密分行，保持字腔和正常字形。

选纯字、摄影或原创插画分支：产品需要轮廓清楚，人物可抠图/斜边分块，蓝紫青叙事插画可选；不能依赖原选手、角色、Logo和赞助商建立风格。

按载体调整构图而非把海报贴上样机。包装必须处理正侧面，衣物收在可印区域，导视箭头与目的地保持完整且高对比。动态如用户要求，先取得可实看的视频证据；本包不声称复现完整运动系统。

位图或效果图使用可用图像生成工具，参考先查看；需要可编辑平面稿则按用户格式排版，明确与效果图的区别。自包含提示词见 [提示词模板](references/prompt-template.txt)，物料配置见 [物料配置](references/prompt-profiles.json)。填入完整任务后实际出图，不仅交付提示词。不得添加未经给定的价格、性能、认证或官方身份。

逐张核对文案、宽重字块、电性长尖、手势密度、主次、承载物。发现问题针对修改并重新查看；连续两轮未解决时如实记录。服装必须留领口/侧缝/袖口/下摆空区；导视功能箭头不能被装饰笔势误导。评价清单见 [evaluation.md](references/evaluation.md)。

交付成品、实际使用的完整提示词、使用的参考和修订记录。说明AI生成、概念或可编辑状态，以及印刷/制造/远读尚未验证的项目。公开发布或覆盖用户已有资产前核对最终范围。

## 十二维检查

### intent
BREAK OUT 的突破感可由倾斜变大的字、撕接和手写注释观察；这是视觉解读，不冒称完整官方策略。

### identity
圆形花焰标识与倾斜 BREAK OUT 组成识别分支；最小尺寸、留白规范未知。

### typography
窄高粗体用于大年份与名单；倾斜且字形逐步放大的口号是另一分支，字体名未知。

### color
灰白黑加荧光绿，官方分组标题偏黄绿；来源压缩与不同画面可能造成颜色差异，未公布标准值。

### layout
城市拼贴可越过视觉分区；三栏信息图保持对齐，外沿竖排为次级边框。

### graphics
粗糙椭圆、X、三角与计数笔触用于注释；大尖角色块也出现在识别分支。

### imagery
灰阶城市拼贴与保留队服颜色的摄影应用并存；没有取得完整原始插画，不能分析其细节。

### surface
颗粒与撕边是画面层构，不能据此推定实际印刷纸张或服装工艺。

### information
名单、组别、身份有稳定层级；荧光绿小字在浅底的可读性需要迁移时加强，不照搬弱对比。

### motion
仅取得官方视频链接与封面/静态应用，未连续观看，不推导节奏、转场、运动轨迹或缓动。

### applications
已观察横向主视觉、名单、合作方署名与摄影应用；没有服装包装导视的官方样本，六例为迁移验证。

### governance
2021 赛事归属由官方两篇文章核实；Murilo 的个人项目页可核实团队分工；密码保护设计师页不访问，第三方动态图资源超时未读取。

## 观察到执行

### R-01 窄高信息字与倾斜放大字
证据：[MSI21-001](../assets/reference/official-03.jpg) / [MSI21-002](../assets/reference/group-02.jpg) / [MSI21-003](../assets/reference/group-01.jpg)。

转译（研究归纳）：以窄高、极粗、紧排正体建立标题和名单；需要冲劲的短语可用倾斜、逐字放大的另一分支，不把所有字统一拉宽。

不变量：字形密度及主次关系，而非具体字体名称。

可变参数：正体适合信息，倾斜放大仅用于短标题；中文选窄而有力的字面。

反例：沿用 MSI 2024 超宽粗字或通篇斜体会混淆系统。

验证：横幅与密集海报均能区分标题、口号和小字。

### R-02 灰黑底与单一荧光绿
证据：[MSI21-001](../assets/reference/official-03.jpg) / [MSI21-002](../assets/reference/group-02.jpg) / [MSI21-003](../assets/reference/group-01.jpg) / [MSI21-004](../assets/reference/official-01.jpg)。

转译（研究归纳）：灰白和黑组织基底，荧光绿到黄绿承担标记与局部主色；允许绿色大面分支，不增加红色或光谱渐变。

不变量：绿色与灰阶的职责关系。色名是目视归纳，非官方色号。

可变参数：主视觉绿色可成大面，名单与导视减少绿色面积并加强文字对比。

反例：把赞助商金红、队服蓝红当成品牌色，或使用彩虹光谱。

验证：去掉品牌名后仍是灰阶/绿色关系，不成为泛霓虹多彩海报。

### R-03 笔触是有方向的注释
证据：[MSI21-001](../assets/reference/official-03.jpg) / [MSI21-003](../assets/reference/group-01.jpg) / [MSI21-004](../assets/reference/official-01.jpg)。

转译（研究归纳）：用粗糙椭圆、X、短划、三角或计数线强调一处内容；保留粗细不均与落笔感，别在必读文字上乱涂。

不变量：人为注释与机器排版形成张力。

可变参数：每种物料可只保留一个标记，远距导视减少或删除小笔触。

反例：均匀发光几何圆环、装饰随机密铺或假数据。

验证：海报标记指向标题或重点，导视箭头清楚且不被涂改。

### R-04 撕边与颗粒的分层
证据：[MSI21-001](../assets/reference/official-03.jpg) / [MSI21-003](../assets/reference/group-01.jpg) / [MSI21-004](../assets/reference/official-01.jpg)。

转译（研究归纳）：颗粒覆盖灰阶图像/底层，撕边用于分开图像和文字平面；小字用相对干净区域，勿把噪声压在正文。

不变量：粗糙图像层和规则信息层的对照。

可变参数：织物保留实际纤维，颗粒只是印花，不能把纸张材质当衣服。

反例：全图均匀脏化、做旧泛黄或 MSI 2026 式红色爆裂。

验证：包装折面与刊物的撕边有分区作用，文字仍可读。

### R-05 拼贴突破与规则网格并存
证据：[MSI21-001](../assets/reference/official-03.jpg) / [MSI21-003](../assets/reference/group-01.jpg) / [MSI21-004](../assets/reference/official-01.jpg)。

转译（研究归纳）：主视觉允许照片撕接、标题跨区；信息稿保留清楚栏列与对齐。外沿竖排是次层，不替代主信息。

不变量：内容越密，信息区越稳定；自由只作用于主体层。

可变参数：横幅可左右切分；竖版可上字下图；窄载体删去外沿小字。

反例：把所有内容排成任意倾斜碎片，或把一张构图贴到所有载体。

验证：高密度海报有明确阅读顺序，横幅有横向阅读路线。

### R-06 灰阶拼贴与彩色摄影分支
证据：[MSI21-001](../assets/reference/official-03.jpg) / [MSI21-004](../assets/reference/official-01.jpg) / [MSI21-006](../assets/reference/players.png)。

转译（研究归纳）：核心城市图像用高反差灰阶颗粒；人物现场摄影应用可以保留真实颜色。新品牌使用原创图像，不复制赛事人物、城市照片和标识。

不变量：图像处理与信息关系可迁移，赛事身份不能迁移。

可变参数：包装可无照片，服装转为平面印花；是否灰阶依子系统决定。

反例：把未看到的角色插画、MV节奏或全套摄影标准编成既定规则。

验证：新的城市骑行题材无需 MSI 标志也能呈现相同排版关系。

### R-07 身份与证据边界
证据：[MSI21-002](../assets/reference/group-02.jpg) / [MSI21-005](../assets/reference/official-02.jpg) / [MSI21-006](../assets/reference/players.png)。

转译（研究归纳）：保留自有品牌，明确概念与实际；赞助标识、赛事花焰、BREAK OUT 原口号和选手身份不用于新品牌。

不变量：借鉴机制与官方资产分开。

可变参数：包内列出来源与未核实内容，按材料用途调整。

反例：依赖赛事标志才能辨认风格，或把研究建议写成官方规范。

验证：六例仅出现任务给定身份和文案，没有官方联名、产品性能或虚构价格。

## 迁移边界

六例采用虚构 UPSHIFT 城市骑行/概念周边，不声称真实活动、同一 SKU 或与 Riot 合作。没有做 Skill 与 Prompt 的受控对照。概念图审查不等于印刷制造、承重性能、认证或实景观看距离验证。官方样本中的弱对比小绿字不照搬到功能信息。

# Worlds 2017 · 修订版：光滑冷调浮雕与金色书写

本次修正三件事：动物题材与风格机制解耦；网页从四张合并图解扩为八项独立分析；把过深石裂和纯白材质改为连续光滑、浅细纹、冷白高光与主体蓝灰中间调。

## 证据与用词边界

[创作方案例](https://www.pepperez.work/work/worlds-2017) 明示木雕 Mudiao 形态、白色大理石、金色与书法。“白色大理石”是来源对材质的描述；“釉状光泽”“冷色珠光/偏光感”是依据画面的观感归纳，不确认真实陶瓷釉、偏光涂层、薄膜干涉或物理渲染参数。具体粗糙度数值、灯光参数和官方标准色均未知。

必须把两个深度分开：**形体与形体之间的结构暗腔可以深；材质表面的纹理要细、浅、轻。** 蓝色必须进入雕塑的转折和背光面，不是把纯白物体放进蓝背景就足够。白色高光不应填满整幅主体。

五张原作均已亲看，完整像素和来源登记见 study.json。用户补充的原作截图用于重新校准同一主视觉的材质与光色，不算新的独立设计应用证据。应用合集含示意对阵，城市日期不作为真实赛程；逐图制作人员及所有展示稿的实发状态未核实。

## 八项细分分析

### 1. 形态：交叠浮雕，不限定动物

**已观察**：完整主视觉中兽形、盘云和装饰构件相互穿插，曲线方向带动视线；身份题材是兽形，造型机制是多层实体的交叠与盘绕。 [原像素图解](../assets/analysis/v2-form.svg)，来源 W2017-002，原图 ref-010.jpg，完整画面。

**复现建议**：先选与品牌内容有关的主体，再把它组织成有前后遮挡的实体浮雕；植物用花瓣叶脉，建筑用拱洞台阶，器物用环件齿轮，不默认补龙、鱼、羽毛。

**不变量**：层叠实体、连续动势、清楚的前后关系。 **可调参数**：题材、曲线/直线比例、尺度和裁切。

**反例**：只换成另一种动物，不能验证跨题材；只加石纹但保持孤立物件，也没有交叠语法。 **验证**：植物、机械、建筑三例去掉动物后，仍检查形体、光色、字层与密疏。

### 2. 光色：冷白高光与蓝灰转折

**已观察**：兽头与隆起边缘有冷白高光，较大转折面与后景形体呈蓝灰至海军蓝；蓝色进入主体，而不只在背景里。曲面可见连续、带冷色倾向的掠射亮带。 [原像素图解](../assets/analysis/v2-light.svg)，来源 W2017-002，原图 ref-010.jpg，裁切像素 x,y,w,h=(440, 130, 1260, 930)。

**复现建议**：用少量冷白亮脊、较宽蓝灰中间调、海军蓝背光面建立体积；控制曝光，不能让主体大面积变纯白。以轻微珠光/釉状冷色反射描述观感，未核实真实偏光或干涉材质。

**不变量**：主体内部冷白—蓝灰—深蓝的连续明暗与色相过渡。 **可调参数**：光向、明暗范围、冷调强度、景深；色彩随原参考校准。

**反例**：纯白瓷雕放在蓝背景上，或整体覆盖蓝滤镜；夸张彩虹偏光、荧光青都偏离证据。 **验证**：看植物叶面、建筑转折墙面、机械环件侧壁是否有蓝灰半调，文字和金边是否仍分离。

### 3. 表面：釉状光泽与浅细纹

**已观察**：白色雕刻表面连续、相对光滑，曲面亮带较柔和，边缘圆润；细纹浅而轻。明显深暗多来自鳞片、云形与形体之间的结构缝，不应转译为表面深裂。 [原像素图解](../assets/analysis/v2-surface.svg)，来源 W2017-003，原图 ref-011.jpg，裁切像素 x,y,w,h=(260, 100, 1060, 710)。

**复现建议**：采用低粗糙度、柔和连续高光、轻微釉状/抛光白石观感；细纹只做淡而浅的表面迹线，不做开口裂缝、崩边或粗颗粒。来源称白色大理石；“釉状”是视觉比喻，不确认陶瓷釉。

**不变量**：光滑连续表面、柔和亮带、细浅纹理；结构深、表纹浅。 **可调参数**：浅纹密度与可见度、表面反射强弱；远读和印花主动删细纹。

**反例**：粗裂风化石、毛糙混凝土、遗迹崩边；或没有微表面的塑料镜面与果冻透明。 **验证**：放大检查表纹是否像裂开的沟；缩小后纹理应退到形体和文字之后。

### 4. 色彩职责：深蓝承托，金色提边

**已观察**：近黑海军蓝承接负空间；雕塑冷白与蓝灰对照；金色只沿部分结构边缘发亮，书法也是金色但属于较平的图形层。 [原像素图解](../assets/analysis/v2-palette.svg)，来源 W2017-001，原图 ref-012.jpg，完整画面。

**复现建议**：把背景、冷调实体、反光金属边、平面书法分成不同职责。金属高光比白石亮带更集中，金书法不必拥有同一镜面材质。不要通体镀金。

**不变量**：冷色大面积承托少量暖金；图形金和金属金不混为一种表面。 **可调参数**：金色占比、位置、明暗与冷暖；无官方标准色值可用。

**反例**：满幅黄金融化、浅白背景配金字、暖黄光把全部白石照成奶油色。 **验证**：检查金边是否服务轮廓、主体是否仍蓝灰；去掉金色后主体深度也应成立。

### 5. 文字：书写情绪与窄高信息

**已观察**：大号金色纵向书法自由伸展，较小白色拉丁文字窄高，徽记与小信息另沿清晰轴排列；字的形态与排布承担不同任务。 [原像素图解](../assets/analysis/v2-type.svg)，来源 W2017-001，原图 ref-012.jpg，裁切像素 x,y,w,h=(45, 0, 510, 723)。

**复现建议**：短主标题可用自由书写，支持信息用有序窄高无衬线字；中文功能字属于研究者延伸，非已核实的原赛事规范。短目的地、阶段名或产品名采用自然偏长的无衬线中文字面，中等或稍轻字重，笔画利落、收笔干净、字腔开放，以视觉重量而非相同字号呼应窄高英文。不要机械压缩粗黑字，也不要把功能字写成书法。中文与英文共轴、组间留白清楚，按视觉重心微调字距，不强求两行同宽。长句和小字恢复较常规字宽与清晰笔画，避免全部窄化或细成发丝。情绪短标题仍可用金色书法，中文功能字与箭头保持浅色高对比。新品牌字标可单独设计，不当作原赛事字体。

**不变量**：自由大字与有序小字之间的张力。 **可调参数**：横竖排、字号、行数和新品牌字标；官方字体家族未核实。

**反例**：把所有小字都写书法，或把所有信息换成古典奢侈品衬线字。 **验证**：横幅和封面逐字核对；情绪标题强而不吞掉信息，导视目的地更优先。

### 6. 构图：局部裁切与密疏分区

**已观察**：小组赛主题展示稿以巨幅局部占右侧，左侧保留暗色信息带；完整双兽场景则更满。九宫格显示完整场景与大裁切共存。 [原像素图解](../assets/analysis/v2-layout.svg)，来源 W2017-001，原图 ref-012.jpg，完整画面。

**复现建议**：按画幅选择完整雕塑或近景局部，让密集形体与安静文字区产生对照；横幅裁局部，竖版延展主体，不固定复制左右分栏。

**不变量**：密集图像与稀疏信息的对比、阅读区不被高光挤压。 **可调参数**：主体位置、裁切方向、占比、信息带宽度。

**反例**：整幅等密度纹样，或同一张完整海报按比例贴满所有物料。 **验证**：3:1横幅、3:4海报和密信息封面采用不同裁切，仍清楚识别文字。

### 7. 信息：识别、阶段、细节分组

**已观察**：左侧白色徽记与小字形成独立组，阶段、城市、日期按小段组织，和大金书法不在同一阅读级；展示稿数据不作为实际赛程。 [原像素图解](../assets/analysis/v2-information.svg)，来源 W2017-001，原图 ref-012.jpg，裁切像素 x,y,w,h=(75, 255, 170, 335)。

**复现建议**：先排识别、主讯息、功能细节三级，再按共同轴分组；密度提高时保留组间距离。导视让目的地与已给箭头高于装饰，不能用小字硬填。

**不变量**：信息层级可辨、相关内容成组、功能内容可读。 **可调参数**：级数、行数、组距和对齐；没有官方字号/网格数值证据。

**反例**：徽记、标题、日期等大争抢；小字埋在雕塑高光与细纹中。 **验证**：封面同时读出刊名与专题，导视能先读方向和目的地；不借展示稿推断真实赛程。

### 8. 分支与适配：同语法，不同载体

**已观察**：九宫格同时有暗底雕塑、大裁切、浅底人物和对阵探索，说明不是全年度只能暗底兽形；具体展示稿实发状态未全部核实。 [原像素图解](../assets/analysis/v2-branches.svg)，来源 W2017-004，原图 ref-009.jpg，完整画面。

**复现建议**：当前六例测试暗底雕塑主线的跨物料迁移。植物最接近盘绕动势；建筑和机械是进一步迁移，不能宣称完整复刻原叙事气质。包装分正侧、衣服胸小背大、导视删细节。

**不变量**：依据主题选择分支，依据观看距离和承载物调整信息与图像。 **可调参数**：题材、画幅、图像占比、印花复杂度和功能优先级。

**反例**：动物图贴六个样机就宣布全部适配；又或把别的分支强套暗底主线。 **验证**：三类非动物+三类载体示例；检查纸/布/导视保持自身材料和阅读职责。

## 跨题材结论

动物是原作的重要叙事资产，删除后无法保留完全相同的故事气质，但雕塑组织、冷调光色、光滑浅纹、局部金边、书写与信息对照可以转移。植物的曲面和盘绕结构较接近原图的形态逻辑；建筑和机械更容易偏向空间模型或黑金产品广告，须同时检查八项关系，不能只凭颜色和石材通过。

本轮三类非动物实际生成，六类物料仍完整。新图均为研究者的迁移概念，不是原年度存在这些题材的证据。六例重新核对文字、光色、表面和媒介表现；仍未做印刷制造、现场远读或动态验证。全部旧轮次保存，过粗纹理和过白轮次不再作为最终示范。

## 中文功能字延伸 · 研究者适配建议

原作英文能观察到窄高、利落、节制的字形；现有原素材不足以确认对应的中文功能字字库与规范。本节是为中文应用补齐的设计建议，不反向认证原赛事规则。

| 文字职责 | 中文适配 | 与英文的关系 |
| --- | --- | --- |
| 情绪与主张 | 短句可保留自由金色书法 | 与有序信息字形成对照 |
| 目的地、阶段、短产品名 | 自然偏长的无衬线字面，中等或稍轻字重；笔画利落、字腔开放 | 呼应窄高英文的节奏与视觉重量，避免粗宽方块压过英文 |
| 长句、说明、小字号 | 较常规字宽、稳定清晰笔画，行距与分组优先 | 延续秩序与留白，不复制英文的极窄比例 |

中英文共用对齐轴，但不强求同字号、同宽或相同字符比例。字距依中文内部空间和英文大写竖笔的视觉重量微调，不能简单拉开全部汉字。优先选择本身字面稍长的中文字体，不把粗黑字机械横向挤瘦；也不新增未经核实的官方字体名或授权声明。

导视验证：原“主展厅”粗宽字过重；第3轮只轻微收窄，仍未通过；第4轮明显减轻笔画、打开字内空间，保留自然可辨的三个汉字，采用为当前概念。MAIN HALL、向右箭头、釉状浅纹与主体蓝灰光色保持。小字号和实际观看距离仍需单独打样。

# Worlds 2017 · 白石浮雕与金色书写

为用户实际完成指定物料。先确定比例、品牌、必需文案、承载材料和观看场景；低风险概念可采用明确标记的虚构简报，关键缺口才询问。

## 设计决策

先看 [原作证据](references/visual-evidence.md)，按任务选择整体雕塑、局部或信息编排参考。遵循八项关系（完整观察、反例和验证见 [细分指南](references/style-guide.md)）：

- **形态：交叠浮雕，不限定动物**：先选与品牌内容有关的主体，再把它组织成有前后遮挡的实体浮雕；植物用花瓣叶脉，建筑用拱洞台阶，器物用环件齿轮，不默认补龙、鱼、羽毛。
- **光色：冷白高光与蓝灰转折**：用少量冷白亮脊、较宽蓝灰中间调、海军蓝背光面建立体积；控制曝光，不能让主体大面积变纯白。以轻微珠光/釉状冷色反射描述观感，未核实真实偏光或干涉材质。
- **表面：釉状光泽与浅细纹**：采用低粗糙度、柔和连续高光、轻微釉状/抛光白石观感；细纹只做淡而浅的表面迹线，不做开口裂缝、崩边或粗颗粒。来源称白色大理石；“釉状”是视觉比喻，不确认陶瓷釉。
- **色彩职责：深蓝承托，金色提边**：把背景、冷调实体、反光金属边、平面书法分成不同职责。金属高光比白石亮带更集中，金书法不必拥有同一镜面材质。不要通体镀金。
- **文字：书写情绪与窄高信息**：短主标题可用自由书写，支持信息用有序窄高无衬线字；中文功能字属于研究者延伸，非已核实的原赛事规范。短目的地、阶段名或产品名采用自然偏长的无衬线中文字面，中等或稍轻字重，笔画利落、收笔干净、字腔开放，以视觉重量而非相同字号呼应窄高英文。不要机械压缩粗黑字，也不要把功能字写成书法。中文与英文共轴、组间留白清楚，按视觉重心微调字距，不强求两行同宽。长句和小字恢复较常规字宽与清晰笔画，避免全部窄化或细成发丝。情绪短标题仍可用金色书法，中文功能字与箭头保持浅色高对比。新品牌字标可单独设计，不当作原赛事字体。
- **构图：局部裁切与密疏分区**：按画幅选择完整雕塑或近景局部，让密集形体与安静文字区产生对照；横幅裁局部，竖版延展主体，不固定复制左右分栏。
- **信息：识别、阶段、细节分组**：先排识别、主讯息、功能细节三级，再按共同轴分组；密度提高时保留组间距离。导视让目的地与已给箭头高于装饰，不能用小字硬填。
- **分支与适配：同语法，不同载体**：当前六例测试暗底雕塑主线的跨物料迁移。植物最接近盘绕动势；建筑和机械是进一步迁移，不能宣称完整复刻原叙事气质。包装分正侧、衣服胸小背大、导视删细节。

原作另有白底人物与对阵探索；用户选择该分支时查 [风格指南](references/style-guide.md)，不要强行套暗底。具体字体、标准色号、网格和运动参数没有证据。本包只把已有观察转译为规则，不虚构官方规范。

## 制作与物料

读 [物料配置](references/material-profiles.json) 中当前物料：包装分配正侧职责，横幅选择局部并留文字带，服装采用胸小背大，导视以目的地和箭头为主，封面安排密信息。原赛事徽记、奖杯与兽形只供研究；用户未要求沿用身份时使用原创品牌与原创主体。

选择交付工具：需要位图或实体概念时实际调用可用图像生成工具，并遵循其 imagegen 指南；需要可编辑版面时使用排版工具。将 [自包含模板](references/image-prompt-template.txt) 填完整后发送，提供已选择的参考图并注明“风格参考，非编辑目标”。不要让出图模型先读网站或 Skill。记录实际发送文字、参考、工具、轮次和输出；工具不可用时说明案例未生成。

## 审查与交付

逐张核对文案、形体深度、光滑浅纹、主体蓝灰半调、克制冷白高光、少量金边、书法/信息对照、密疏及承载材料；导视还核对方向，以及中文短功能字是否粗宽过重、字腔是否清楚、中英文是否在视觉重量与对齐轴上协调。生成器可能自动把小字改成古典衬线或复制参考兽头，出现后针对问题修订，不靠近似配色判通过。同一缺陷两轮仍未解决则记录未通过并交付可独立完成部分。

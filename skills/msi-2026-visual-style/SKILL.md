# MSI 2026 视觉转译工作流

## 适用场景与边界

用于把 MSI 2026 样本中的视觉关系转译到用户品牌的任意物料；也可只输出设计方案或审查已有作品。先确定用户要“方案 / 制作 / 审查”中的哪类交付，不把所有任务缩减为一段绘图提示词。

这是独立研究 Skill，不是官方品牌手册。字体名称、精确色值与承制团队未核实。参考图为官方作品，分析图与规则为研究提炼，生成示例不是官方作品。

## 1. 建立任务简报

提取物料、品牌或产品、必须准确出现的文案、尺寸、观看场景、输出方式及约束。只有缺失信息实质影响执行才询问；可补足的内容写为假设。未给定的产品性能、认证和数字保持为空。

需要结构化输入时填写 [brief.json](assets/templates/brief.json)，可运行：

```text
python scripts/prepare_brief.py --input brief.json --output work/
```

脚本校验必要字段，输出 design-brief.md、prompt.txt 与 review.json；它整理输入与检查清单，不负责出图，不判定视觉合格。无 Python 时按相同字段手工处理。

## 2. 选取证据，判断视觉分支

阅读 [研究依据与规则边界](references/vi-audit.md) 和 [风格指南](references/style-guide.md)，查看其中本地原图与 [视觉证据索引](references/visual-evidence.md)。按任务选图，按需阅读。

- 信息主导（002/004）：先规则分组，再选红色圈划、下划线或边缘裂口；黄色可不用，或按重点少量分布。不强制中心爆裂，不要求四色齐全。
- 形象主导（008/010）：可使用中心/偏心放射裂口与大识别锚点；它是可选构图，不是所有物料的固定模板。
- 叙事与实物（001/010/007）：插画可深底或浅底，以棱角、硬边、方向线与平面语言相接；角色与产品可有自身颜色。实物保留真实材质，不把服装或产品本体强制灰纸化。
- 照片、客户端与早期城市海报属于应用或背景证据；不能把客户端深色 UI、城市蓝天推成核心纸灰系统的必选规范。

逐图出处及用途见 [sources.json](references/sources.json)。记录实际采用的样本 ID，区分观察、推导和假设。视频仅提供来源链接，离线执行不依赖联网观看。

## 3. 先形成设计方案，再制作

按 [物料适配规则](references/adaptation.md) 输出简短设计规格：

1. 信息排序：主识别、辅助信息、细则；指出各层对应用户哪段文案。
2. 版式草案：主体位置、信息分区、对齐轴、阅读顺序、留白及裁切边界。
3. 视觉分工：按所选分支组织识别、信息与自由笔触；黄色是可选强调，信息稿可用圈划/下划线代替爆裂。标题、正文、页脚分层；中文保持自然字形，不机械拉宽。参照002/004/008的关系，不复制赛事字标和身份资产。
4. 素材方案：参考只用于研究，正式图形、品牌和插画使用用户素材或原创内容。

方案明确后用当前环境已有的设计或图像能力制作。不为执行本 Skill 擅自安装工具、索取密钥或上传到第三方。只有文字能力时交付可执行设计规格、所选参考和明确限制，不声称已制作视觉。[提示词模板](references/prompt-template.txt) 是供出图模型直接使用的自包含规格，不替代本 Skill 的 Agent 工作流。可按 [物料配置](references/prompt-profiles.json) 匹配构图重点，再结合用户场景、主体和呈现要求填充；prepare_brief.py 已包含该匹配逻辑。流程更完整不代表画面质量必然更高，不将两种形式的效果作无依据排名。

## 4. 用证据审查并修正

按 [检查标准](references/evaluation.md) 对照实际成品，记录“通过 / 需修改 / 未验证”及证据位置，不能只把清单全打勾。先修正文案、产品承诺和可读性，再调整风格。迭代时指出具体缺陷和定向修改方法；连续两次同类修改无改善时说明限制，不无限重试。

跨物料系列比较色彩职责、字重、规则信息与自由笔触的关系，不要求相同构图。包装渲染不能证明刀模、材质、印刷或量产可行性。

## 5. 输出要求

- 交付用户要求的可用作品；生成概念标为“生成验证样例”。
- 附简短设计说明：采用的样本 ID、视觉分工、物料适配及关键假设。
- 附审查结果及待修正项；制作方式、实际文件、提示词（如使用）和未验证项可追溯。
- 方案任务交付设计规格，审查任务交付有位置与改法的问题单；不强制无关文件。

## 禁止事项

不将近似字体、色值和推导比例写成官方规范；不复制赛事、战队标识或角色冒充用户品牌；不虚构性能、认证、活动信息和合作关系；不让裂口遮住必要文字；不以创建目录或提示词代替完成设计。参考图权利归 Riot Games 及相应权利人。完整包可离线读取，不假定目标 AI 能访问私有网站，不自动安装。

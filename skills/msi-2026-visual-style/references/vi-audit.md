# MSI 2026：VI 分析与转译依据 v2

结论：现有六项不是方向错误，而是把主视觉中的一种表达过度推广成了整个系统。应从“纸灰＋黑字＋红色爆裂＋黄色划线”升级为“按信息任务选择标记、构图与叙事分支的设计语法”。网站、专属 Skill、独立 Prompt 和物料配置必须同步；只改展示文字不能纠正后续出图倾向。

本版沿用已认可的四章与 PC 三栏结构，将审查发现落实为八项图解、专属 Skill、独立 Prompt 和六类新生成案例。规则属于研究归纳，官方原作与生成验证分别标注。

## 不变量、变量和反例

不变量是识别与信息的清晰主次、规则对齐与自由标记之间的对比，以及可识别的笔触/裂口语言。它们是跨样本的研究归纳，不是官方发布的统一规则。

可变量：是否用黄、图形属于哪一族、红色占比、图形中心、画幅、列数、密度、插画主体配色与实物材质。黑白/单色印刷可优先保留字重、层级和轮廓节奏，但属于待验证适配，不宣称官方已规定。

反例：把一张名单图强行套成中心大爆裂；为了四色齐全而给每个分组都涂黄色；把所有文字都变宽重；把真实织物换成纸张；为了“避金属质感”改掉用户产品本来的金属；复制游戏角色和赛事字标来建立识别。

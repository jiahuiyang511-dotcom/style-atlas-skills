# 实际成品检查

每项记录状态、证据位置和修改动作；看不到成品时标“未验证”。脚本不替代视觉判断。

| 维度 | 通过依据 | 修改动作 |
| --- | --- | --- |
| 文案与事实 | 逐字比对简报；无新增性能、认证或合作暗示 | 删除新增信息，修正文案 |
| 阅读锚点 | 目标尺寸主标题先被识别，正文有独立清晰分组 | 减少竞争图形，拉开字重与组距 |
| 色彩角色 | 符合所选分支；黄色可缺席，存在时服务明确重点 | 检查图形族选择与信息密度；减少无功能的黄标或红色 |
| 图形关系 | 所选圈划、下划线、箭头或裂口有明确功能，与规则信息形成对比 | 不强制中心爆裂；重画原创轮廓，避免均匀满铺 |
| 纹理 | 近看可感，目标尺寸不吞字 | 降低颗粒对比，小字区减弱 |
| 物料适配 | 按观看距离、分面、裁切和操作区调整 | 重排分区，而非缩放参考图 |
| 来源与原创 | 能指明所用样本；不拿官方标识当用户品牌 | 换原创主体，区分观察与推导 |

结论分别记录视觉关系、可读性、物理生产是否验证。六类概念样例也不能证明任意物料泛化。

## 跨物料回归重点

先检验高密度信息、无黄色和非中心爆裂是否仍可辨识；再检验原创插画分支。旧版案例不回填新版规则 pass；新版逐例记录实际观察。动态、印刷和制造不因结构校验或概念出图而通过。

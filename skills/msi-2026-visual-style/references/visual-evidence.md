# 视觉证据索引

原图是官方样本；8 张图解为研究标注。下列裁取在 SVG 内直接取景，未用 AI 重画。

- [字体与编排图解](../assets/analysis/01.svg)：MSI26-004 标题 / 正文 / 页脚。宽重标题建立入口，较轻正文承载解释，窄字或等宽感页脚收束细节。迁移时保留层级对比，中文保持自然字形；字体名称未核实。
- [色彩系统图解](../assets/analysis/02.svg)：MSI26-002 / MSI26-004 / MSI26-008。灰白承托信息，黑色建立识别，红色标记制造张力。黄色按任务出现：名单可无黄，权益可多处强调；插画和实物保留自身配色。
- [构图图解](../assets/analysis/03.svg)：MSI26-002 名单 / MSI26-004 权益。名单以重复单元对齐，权益按主辅栏分组，主视觉则集中识别。先选择阅读骨架，再安排突破网格的笔触；列数、密度与留白随内容调整。
- [图形语法图解](../assets/analysis/04.svg)：MSI26-002 / MSI26-004 / MSI26-008。圈划连接标题和重点，箭头提供方向，边缘裂口与放射爆裂创造张力。根据内容和密度选择，不必每件物料都使用中心爆裂。
- [纹理表面图解](../assets/analysis/05.svg)：MSI26-002 / MSI26-008。低对比颗粒和刮擦在空白处提供纸感，小字区域保持安静。转到织物或产品时保留真实基材；具体纸种和工艺未核实。
- [信息层级图解](../assets/analysis/06.svg)：MSI26-004。主标题、组标题、正文和页脚各占一层，统一对齐轴与组距。方向箭头先服务目的地识别，装饰再进入剩余空间。
- [识别组合图解](../assets/analysis/07.svg)：MSI26-008 / MSI26-004 / MSI26-010。大字标稳定识别，页脚把品牌和元信息分组，顶部重复标志形成节奏。转译这些组合关系时，换成用户自己的品牌与原创标识。
- [图像分支图解](../assets/analysis/08.svg)：MSI26-001 / MSI26-010 / MSI26-007。深浅底插画以棱角、硬边色块与方向线呼应平面语言；角色保留主体配色。摄影和服装展示真实材料，不强制变成四色灰纸画面。

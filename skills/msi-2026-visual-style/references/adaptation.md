# 物料适配判断

不变量是视觉角色与阅读关系，而非固定坐标、面积百分比或列数。

| 条件 | 版式决策 | 失败条件 |
| --- | --- | --- |
| 少量文案、远距观看 | 标题为锚点，爆裂围绕或从边缘进入 | 标题被切断、关键日期太小 |
| 多条信息或名单 | 先分组、对齐和建立重复单元，再添加装饰 | 笔触穿过小字、组距混乱 |
| 包装或曲面 | 先划分正侧面、折线及不可用区，再安排图文 | 关键文案跨折线、虚构规格、透视不可读 |
| 网页或互动界面 | 标题与局部形象承载风格；正文和控件清晰 | 装饰假冒控件、运动影响操作 |
| 服装与大尺度载体 | 按观看距离和接缝选择细节与识别空间 | 纹理印不出、品牌被接缝切断 |
| 插画叙事 | 原创主体、硬边与方向线；另设规则信息区 | 抄用官方角色、无理由深底、丢失层级 |

用户指定尺寸、密度或材质优先；若与阅读或形态冲突，指出冲突并提出可检验调整。颜色近似仅辅助屏幕沟通；印刷与荧光效果需另行打样。

信息密集任务优先圈划、下划线和边缘标记，允许无黄色；少信息形象稿可放大裂口。小面积或单色印花优先保住字重、层级、轮廓，颜色删减属于待验证适配。真实织物、产品颜色和金属/玻璃属性由任务决定，不被“纸感”替换。

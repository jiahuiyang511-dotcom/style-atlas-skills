# MSI 2024：黑红锚点与光谱异常体

独立视觉研究，2026-10-21。原图为证据，图解为研究注释，案例为 AI 原创概念；均不代表官方规范。

## 范围与来源

研究 2024 成都 MSI 的事件视觉识别，排除微星电脑品牌、其他 MSI 年份、网页推荐的 Netflix 项目。优先复用本机资料，补充 [Studio Dumbar 原项目](https://studiodumbar.com/work/msi-24)。品牌设计署名由创作方原页核实；[Stan Zienka 自述](https://www.behance.net/gallery/212675447/MSI-2024)的搜索摘要可见，但页面返回 403，未读取其图片，不据此增加视觉观察。

## 十二维核对

### intent
创作方把 mysterious、dangerous、powerful 作为方向；本研究译为危险感、未知感与受控秩序。

### identity
赛事字标与花焰符号形成锁定组合；比例和最小尺寸未核实。

### typography
主图与重复字墙均为超宽重字、紧凑堆叠；具体字体名称未知。

### color
黑红构成锚点，光谱沿有机边界出现；旗帜与字墙证明纯黑红分支成立。

### layout
大文字体块与外围微数据并列；下三分之一以稳定黑条承载白字。

### graphics
异常体光谱边界与 Empyrean Shapes 为创作方说明的不同构件，不能混称同一图标。

### imagery
Nocturne 光谱硬面属于叙事分支；实景摄影是应用证据。

### surface
主图为平滑数字场与轻微画面颗粒；不推断纸张、织物或印刷工艺标准。

### information
装饰性数据弱于大字；功能信息在转播黑条内清晰分层。

### motion
已查看约每两秒抽帧序列，可见字标、口号、黑场及光谱覆盖状态；未连续播放，不推导缓动、节奏或精确时序。

### applications
旗帜、舞台、工作区、转播样本表明不同触点采用不同密度和色彩面积。

### governance
年份为 MSI 2024，创作方 Studio Dumbar/DEPT®，Riot 美术指导来源另有 Stan Zienka 项目自述；Netflix 推荐图已剔除。

## 可执行规则、反例与验证

### R-01 超宽重字形成结构
观察依据：[MSI24-001](../assets/reference/msi24-brand-expression-1-black-16x9.jpg) / [MSI24-007](../assets/reference/living-hold-b-16x13-rerender-2-02.jpg) / [MSI24-008](../assets/reference/transitions-3_1-04.jpg)。

转译规则（分析归纳）：大标题用超宽、极粗、低行距无衬线大写；以少数紧密行组成视觉体块，小字保持独立对齐。

不变量：字体名未核实；中文以宽重字面及低行距转译，不强行拉扁细字。

可变参数：标题边缘可裁，日期地点不能裁。

反例：细长科幻字与宽松字距会丢失此关系。

检验：去掉色彩和赛事标志后，标题仍形成有力量的文字结构。

### R-02 红黑锚点与局部光谱
观察依据：[MSI24-001](../assets/reference/msi24-brand-expression-1-black-16x9.jpg) / [MSI24-002](../assets/reference/srx_banner_flags-2.png) / [MSI24-007](../assets/reference/living-hold-b-16x13-rerender-2-02.jpg)。

转译规则（分析归纳）：先决定黑红主关系，再让紫、青、绿、黄沿一个有机边界连续过渡；允许纯黑红分支。

不变量：黑红负责识别，光谱负责异常能量；颜色描述为目视归纳，非官方色号。

可变参数：黑底或红色中心可互换，光谱面积按物料减少。

反例：全幅均匀霓虹渐变、纸灰红爆裂都不是本条目的语法。

检验：缩小到缩略图时，仍能看出主色锚点，不是均匀彩虹。

### R-03 异常体的连续边界
观察依据：[MSI24-001](../assets/reference/msi24-brand-expression-1-black-16x9.jpg) / [MSI24-002](../assets/reference/srx_banner_flags-2.png) / [MSI24-005](../assets/reference/msi-nocturne-detail-01.jpg)。

转译规则（分析归纳）：用连续、有机、鼓胀或拉伸的边界承载光谱，边缘发光而内部保持实色或暗场。

不变量：这是对 The Aberration 的静态转译，具体几何不是官方规范。

可变参数：轮廓可环绕产品、沿旗帜裁切、局部退到边缘。

反例：不能用红色撕纸、手绘黄色圈划代替。

检验：外轮廓要能单独辨认，不成为任意烟雾背景。

### R-04 数据纹理与真实信息分层
观察依据：[MSI24-001](../assets/reference/msi24-brand-expression-1-black-16x9.jpg) / [MSI24-006](../assets/reference/lower-third-cut-07-03.jpg) / [MSI24-007](../assets/reference/living-hold-b-16x13-rerender-2-02.jpg)。

转译规则（分析归纳）：微小刻度、角标只作为背景节奏；必须读取的日期、地点、方向、产品名放在纯色稳定区。

不变量：Journey Data 是创作方命名；复现不复制真实坐标、比分或赛事数据。

可变参数：密集稿增加黑色净区；微装饰可以删去。

反例：让灰色微数据承担必读信息会降低功能性。

检验：导视远看先见箭头和目的地；近看才见辅助刻度。

### R-05 身份与借鉴语法分开
观察依据：[MSI24-001](../assets/reference/msi24-brand-expression-1-black-16x9.jpg) / [MSI24-002](../assets/reference/srx_banner_flags-2.png) / [MSI24-005](../assets/reference/msi-nocturne-detail-01.jpg)。

转译规则（分析归纳）：原创品牌以自己的字标建立识别，不复用 MSI 花焰标志、LoL 角色、赛事口号或赞助商。

不变量：保留尺寸层级与组合关系，不复制专有标记。

可变参数：字标可单色，身份区应保持完整。

反例：靠照搬 MSI 标志才成立，说明迁移失败。

检验：案例换成 PHASE 后仍能成立且不误称官方联名。

### R-06 三维是叙事分支
观察依据：[MSI24-005](../assets/reference/msi-nocturne-detail-01.jpg) / [MSI24-003](../assets/reference/frame-58.png) / [MSI24-004](../assets/reference/msi-brackets-stage.jpg)。

转译规则（分析归纳）：可选择光谱曲面或原创抽象物体，避免把 Nocturne 角色及其轮廓当成通用装饰。

不变量：硬面光谱反射与软的异常边界可并列，但角色资产不能迁移。

可变参数：服装用平面印花；产品用真实材质加局部图形。

反例：把所有载体做成金属火焰雕塑会丢失物料差异。

检验：平面与包装不依赖人物仍成立；物体边缘不遮挡文案。

### R-07 按承载物重新组织
观察依据：[MSI24-002](../assets/reference/srx_banner_flags-2.png) / [MSI24-003](../assets/reference/frame-58.png) / [MSI24-004](../assets/reference/msi-brackets-stage.jpg) / [MSI24-006](../assets/reference/lower-third-cut-07-03.jpg)。

转译规则（分析归纳）：横幅用横向阅读，包装把信息分到正侧面，衣服区分小前标与大背图，导视优先目的地。

不变量：这是复现建议，不是官方物料规范。

可变参数：小面积与远距离应用减少微数据和光谱色。

反例：在衣服接缝、包装折线、方向箭头上堆细节。

检验：六例不能只是同一张海报贴六个样机。

## 不确定性与边界

未取得完整官方 Brand Kit，不声明官方字体、色号、网格、logo安全区或印刷工艺。静态源图与离散抽帧可证明构件状态，不能证明连续动态。六例只检验静态风格迁移，不证明印刷制造、商业授权、实际活动或产品存在。黑红普通电竞设计也可满足部分规则，所以必须同时检查宽重字结构、局部光谱连续边界和信息分层。

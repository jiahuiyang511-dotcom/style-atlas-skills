# MSI 2024 视觉语法迁移

用于新品牌设计时借鉴关系，不复制 MSI / Riot / LoL 标志、口号或角色。此为独立研究转译，不是官方 Brand Kit。

## 接收任务与决策

确认物料、比例、品牌、必须文案和呈现形式；缺项可按低风险概念补足并标注虚构，仅追问会改变结果的内容。先读 [视觉规则与证据](references/style-guide.md)，按 [物料适配](references/adaptation.md) 选黑红简化分支或光谱主视觉分支。

保留四个关系：黑红作锚点；极宽重字紧密叠成结构；光谱沿一个有机轮廓而非均匀铺满；功能信息与弱数据装饰分开。中文延续宽重字面和层级，不冒称官方字体。源图见 [证据索引](references/sources.json) 与 assets/reference，原像素注释见 assets/analysis。

## 制作

按阅读顺序规划标题、主体、功能信息，再选择参考。需要位图就使用环境可用的出图工具及其技能；需要准确多文案可编辑稿则排版制作，不把样机称为生产文件。给模型的自包含模板见 [master.txt](references/master.txt)，按任务填全变量与 [适配配置](references/profiles.json)。输入参考的角色是风格证据，不能要求复刻官方身份。每类物料重新分配内容，不把同一海报贴满所有载体。

## 审查与交付

查看实际输出，检查大字结构、黑红主次、连续光谱边界、文字准确性、功能区对比、方向和承载物。用 [评价规则](references/evaluation.md) 做反证。保存最终实际提示词、参考、工具返回的模型信息（未提供写未知）、真实输出、轮次和逐图审查；失败不标通过。

交付实际作品、提示词与限制。六类样例是概念研究，未验证印刷、制造或实际活动；参考版权属于原权利人。仅抽帧研究不能据此声称复现完整动态系统。发布另按用户授权范围办理。

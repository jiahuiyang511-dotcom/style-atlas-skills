# MSI 2022 视觉语法的原创转译

用于完成设计成果；只要提示词时直接交付自包含提示词。先读取 [视觉指南](references/style-guide.md) 与 [原图索引](references/sources.json)，按任务查看 assets/reference 与 assets/analysis，不把赛事身份搬到新品牌。

1. 确定物料、尺寸、品牌/产品、逐字文案与输出形式。缺少内容可做显式原创概念；参数、认证、价格与真实活动承诺不得自行补写。
2. 先分清必读信息和表现标题。白/浅灰、近黑字为锚；可选薄荷绿到柔黄珊瑚连续色场，或白底少量薄荷绿分支。让细虚线方格贯穿底层，信息按轴对齐。
3. 表现标题用紧缩重字，选择倾斜、反斜、拉伸或适量裁切；不要机械每字加故障。品牌、品名、时间、箭头完整。副信息用干净无衬线/等宽字。Brik 有厂商索引依据，副字体只为档案判断；选字体需有任务适用授权。
4. 一个原创线框球/曲线图为辅助；色场边或图像边可有直角像素阶梯，局部短水平位移。它们不是撕纸、绿笔圈划或光谱液态边。使用原创图像，产品材质和轮廓优先。
5. 按 [物料适配](references/adaptation.md) 取舍后制作：需要位图用可用图像工具，编辑排版稿按所需工具实现。保留实际提示词、参考角色、生成轮次及选定输出。独立 Prompt 见 [master.txt](references/master.txt)，无需模型访问网站。
6. 按 [审查](references/evaluation.md) 逐图查看；修订针对实际缺陷。交付成果、完整 Prompt、修改记录与未验证边界。结构验证不代替美感与文字核对，效果图不代表印刷制造通过。

完整动态未核实；不以静态案例承诺运动节奏。原赛事人物、标志、口号、专有插画不可作为新品牌身份。官方素材权利保留，本包是个人研究及方法转译。

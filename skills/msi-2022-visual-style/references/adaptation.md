# 跨物料取舍

活动海报：方格为底，完整品牌与倾斜专题分级，色场和一个线框图作次级；日程独立成干净对齐块，像素错位不碰时间地点。

产品包装：前面完整品名优先，侧面延续方格和小标，渐变可跨面；像素切口属于印刷图案，避开结构折线。真实纸盒效果不代替展开图。

电商横幅：横向拆为文案区和单一产品区，标题可倾斜但品牌完整；像素阶梯作过渡，产品轮廓与小字保留净区。

服装印花：前胸小标，后背大字和简化网格/线框，降低细线与微字密度；渐变作为印墨而非发光，印花不跨领口袖口或缝线。

活动导视：目的地和方向箭头最大且完整，取消文字故障、彩色映射和微字；薄网格仅在边缘，色场作为辅助分区，确保明暗对比。

刊物封面：完整刊名与可变形专题分开；原创抽象图形或灰阶主体配像素切口，期号稳定，不伪造真实刊号条码。

其他：先确定必读信息与表现标题，再添加低对比方格、柔色场、一个线框图和一处阶梯切口；承载物小则删装饰。

同一产品跨图需要身份一致时用固定参考；本研究包装与横幅是独立概念，不虚构相同SKU。实体图露出主要设计面，服装两个视图完整。

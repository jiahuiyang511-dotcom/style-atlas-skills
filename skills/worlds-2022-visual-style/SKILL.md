# Worlds 2022 视觉语法迁移

使用本技能实际完成设计。先确定物料、受众、品牌、必需文案和比例；缺少非关键内容可采用显式虚构概念。完整系统关系见 [风格指南](references/style-guide.md)，物料决策见 [适配配置](references/material-profiles.json)。

1. 先定显示层、功能层、识别层。拉丁显示字高窄、厚实、紧排，并有不可省略的内部造型：R/D字腔端点的尖弧内收、L内转角钩形、S斜切端头。它们由笔画与字腔轮廓形成，不是外贴装饰、裂纹或模板断口；小字保持技术性与可读性。原作字体为 Manuka Bold 与 Fraktion；须自行核实授权，不能声称随包包含字体。替代字以骨架、开口、字腔和视觉重量筛选，不横向硬挤普通字。
2. 用共同尺度组织字标、索引和文本矩形；横竖可重排，边线保持关系。原创品牌用自己的标识，不描摹盾标、赛事字标或年份锁定组合。
3. 先选主色对：黑白、蓝白或黑铜；四色原页值为 #181818 / #F2F2F2 / #321BDD / #D6B598。其他颜色须有任务原因。改变色彩密度是变量，不把蓝色限制为背景或铜色限定为金属。
4. 主美术的重要元素是印有身份符号的长条织物旗面。观察细织纹、厚度、翻折卷边、聚集叠层、印标随曲面变形；与大平面字形成局部前后遮挡，小字仍清楚。按任务选择旗群、局部旗面、平铺布底或纯平面功能分支。不能用空白丝带、液体、金属触手或旗杆阵列替代。新品牌使用原创符号。

5. 旗帜不是普通布条加纹理。先排方向统一、宽阔连续的旗面群，再加次级微表面：蓝黑细密织点、白铜可有浅网眼；薄边有挺度，大形有张力谷和少量较大波峰，整体哑光配克制掠射高光与窄深遮挡阴影。避免粗麻布、粗棋盘织纹、厚帆布、窄带缠绕环和碎皱堆。真实纤维与软件数值未知，不能把“运动织物般”写成材料认证。

6. 页内位置与空间层级分开选择。旗面可占标题上方、侧方或下方，也可作为前景跨过少量大字边缘；不默认布堆在底、所有字都盖在最前。功能文字保留独立安静平面。至少一例明确验证上部旗面主体与下部大字、局部前景遮挡。

7. 中文保持自然字宽与开放字腔，通过字数、分行、字号和重量延续密度。按受众定中文主或英文主，共用对齐轴，功能字更舒展；此为研究适配，非官方中文规范。
8. 选择适合载体的构图后制作。需要位图时用可用图像生成工具；需要可编辑平面时排版。交付明确区分位图、可编辑源文件、实体效果图；不可把同张海报贴六种载体当适配。
9. 核对大字和细字分工、矩形基准、主导色对、全文准确及使用场景。导视检查箭头；包装检查转角；服装检查印区。至少指出一处尖弧字形和当前分支的旗帜机制；纯平面功能稿记录取舍。不因接近配色就通过。图像未检查时不得报告通过。
10. 交付成品、实际提示词、选用分支和未验证边界。自包含生成模板见 [提示词](references/image-prompt-template.txt)。不要要求模型先访问网页才能理解视觉指令。

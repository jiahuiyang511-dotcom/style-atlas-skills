# Worlds 2019：象牙白纪念碑与浮岛

## 任务与选题

先确认物料、画幅、品牌、必需文字和交付形式；缺信息但可撤销时采用明确标注的虚构概念，不编真实产品承诺。按任务交付实际图像或排版文件，不能只给Prompt就称完成制作。

## 设计决策

先查看 [主视觉参考](assets/reference/lp-01.jpg) 与 [近景参考](assets/reference/lp-00.jpg)。详细观察、来源和边界见 [风格指南](references/style-guide.md) 与 [来源索引](references/sources.json)。

保住四个关系：浅色环境中的象牙白雕塑；完整主形体与连贯主岩体与少量散石构成的悬浮岩基；冷蓝紫背光与少量暖金属；纪念碑体量与远处小岛的尺度差。主形体可取植物、器物或建筑，题材随用户任务，不默认英雄、龙或奖杯。

每座浮岛下面只有一块占主导的连贯主岩体，保留大切面与稀疏层理；旁边只有少量体积明显更小、与主体隔空分开的散石。裂缝属于同一岩体的表面，不把岩基拼成均匀小碎块或碎石堆。

主体不是通体粗糙碎石，也不是无纹塑料。金色放在部件或连接处，避免密集金裂纹。允许近景裁切、偏心构图和减少辅岛，不固定中心主体加两侧角色。不要混入Worlds2017的暗底书法，或区域宣传的红白波纹。

七点原作封面拆解见 [封面分析](references/cover-analysis.md)，生成前先确认主岩体、散石与辅岛是三个不同层次。

## 中外文配对

中文与原语言在设计阶段同步规划，按受众确定主次。保持同一骨架、视觉重量、对齐轴与层级，字号、字重和断行可分别调整。中文笔画较密时先试较轻字重和开放字腔；不机械压窄、不直接套英文疏字距。详见 [中外文搭配](references/multilingual-typography.md)。本次用中文主标题与英文副标题验证；这属于迁移设计，不是官方字体规范。

## 制作

选择参考、先排阅读顺序，再安排主形体与岩基。文字用功能性迁移排版：深灰无衬线与清晰三级层级，中文自然字形、不机械压窄。明确这是研究者适配，官方字体、色号、网格和动态节奏尚未确认。

依 [物料配置](references/material-profiles.json) 处理载体：包装分正侧，横幅留安静文字半区，服装胸小背大且无硬矩形底，导视让目的地与给定箭头先读，封面留信息列。不要把同一海报贴六个样机。

需要位图时使用当前可用图像生成工具，给它实际参考和替换完整的 [自包含模板](references/image-prompt-template.txt)。需要可编辑平面时采用相应排版工具，交代字体和素材来源；图像生成不能伪装成可编辑印刷稿。没有出图能力时明确待生成状态，不用占位图冒充成果。

## 审查与交付

逐张缩小检查是否先读到一块主岩体，再放大检查大切面与稀疏层理。若先读到大量平均碎块，岩基审查不通过。检查文字、方向、冷暖关系、金属密度与承载面；检查新内容离开原赛事身份后是否仍成立。金纹偏多时只减金纹和连接件，不把冷色背光一并洗掉。

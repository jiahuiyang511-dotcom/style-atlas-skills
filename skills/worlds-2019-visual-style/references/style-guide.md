# Worlds 2019：象牙白纪念碑与浮岛

研究日期：2026-10-22。结论：值得制作，资料足够，限定为 LostProject 宣传主视觉系统。此文为分析者归纳，不是 Riot 官方品牌手册。

## 证据与范围

[LostProject 原始项目](https://www.lostproject.com/league-of-legends-worlds-2019) 自述参与现场、社媒、线上宣传、宣传短片和屏幕视觉，列出合作方。本次实际查看五组静态原图，保留原件、原链接及SHA256。主体、近景、群像与应用覆盖支持图像语法，尚不能支持年度完整VI。个人制作分工未进一步核实。

[Eric Zhang 帆船项目](https://ericzhang.design/work/lol-worlds-2019) 属于腾讯区域宣传，红白图形与波纹不能混为核心系统。本次读取了该页文字，未据此推导原图规则。主题曲Phoenix、LV联名与直播UI也未并入。

## 与现有条目的差异

Worlds2017已有暗底、光滑浅纹、蓝灰雕塑和书法关系。本次有交集的是冷白与金属，但关键增量是浅色空间、悬浮岩基、欧洲纪念碑式尺度和主体完整/主岩体连贯、散石从属的材质分层；不是单纯换年份或把2017改浅底。

# 封面主视觉：重新分析的7点

基于已核实的 LostProject Worlds 2019 原作 W19-002，参考 assets/reference/lp-01.jpg，1920×1080。这里的“封面”指风格条目采用的创作方原作主视觉，不以AI生成的刊物封面作为证据。下列观察与转译分开；它们是研究归纳，不是官方标准。

本轮更正：上一版把岩基的大切面、层理误推成了密集碎石，生成图因此过碎。现在以一座岛下方一块占主导的连贯主岩体，加少量隔空散石为主规则；表面裂缝仍可存在，但不能把体块割成平均小块。
## 1. 中心竖轴与两侧拱卫

观察：奖杯占据中央竖向识别轴，左右大型角色与浮岛形成拱卫，前后错位而非机械镜像。转译：先建立一个主视觉体量，再用从属体块围合；迁移时可偏心，但不要让主岩体、辅岛和装饰同时争夺焦点。

证据：W19-002 / 全图；中央奖杯与两侧近景。

![原像素研究图解](../assets/analysis/cover-focus-v2.svg)

## 2. 每岛一块主岩体

观察：埃菲尔铁塔、右侧纪念柱与前景岛下方，各有一块连贯、占主导的岩体。表面的裂缝和层理依附于这块整体。转译：先做一块有重量的悬岩，再处理大切面；禁止用许多同尺寸石块拼出岛底。

证据：W19-002 / 裁切 x530 y365 w285 h265；铁塔岛基。

![原像素研究图解](../assets/analysis/cover-main-mass-v2.svg)

## 3. 散石小而疏，依附主块

观察：小碎块位于主岩体外缘及下方，与主岩有空气间隙，体积远小于主块；远处带建筑的辅岛是另一层。转译：主块先读、散石后读，保留间隙，别把空间塞成碎片云。

证据：W19-002 / 裁切 x485 y370 w335 h320；主块和周边散石。

![原像素研究图解](../assets/analysis/cover-satellites-v2.svg)

## 4. 用尺度差建立远近

观察：左右近景角色与岛体较大，中央后方地标明显缩小；遮挡、反差递减和虚化补充远近。转译：用少量清晰尺度级组织空间，远处岛体简化，不把所有岛做成同等大小、同等锐利。

证据：W19-002 / 全图；近景侧岛与后方地标对照。

![原像素研究图解](../assets/analysis/cover-depth-v2.svg)

## 5. 顶部弧状层带收拢空间

观察：画面上方有跨越左右的弧状石质层带，曲线围绕中央空间延展。它属于环境结构，不是满屏松散云絮。转译：用大尺度弧线收拢主体，细节顺曲面走，避免再叠许多小装饰。

证据：W19-002 / 裁切 x0 y0 w1920 h370；顶部弧状环境。

![原像素研究图解](../assets/analysis/cover-canopy-v2.svg)

## 6. 暖白主调、冷色背光、局部金属

观察：主体与环境以象牙白和灰白为主；岩体背光和底部是冷蓝紫，金属集中在奖杯及角色局部部件。转译：白色保留明暗转折，冷色覆盖受光面而非裂缝发光，金色只建立局部识别。

证据：W19-002 / 裁切 x760 y50 w370 h770；白石、冷影与金属。

![原像素研究图解](../assets/analysis/cover-light-v2.svg)

## 7. 细节随体量分层

观察：角色和奖杯有相对完整的石雕面及受控接缝，建筑有更细的构件；岛体先读大面和层理。转译：不要给所有表面铺同样密的裂纹，缩图看体量、放大看材质；字体与信息网格在该原图中没有证据。

证据：W19-002 / 裁切 x0 y175 w530 h835；雕塑与岩体细节尺度对照。

![原像素研究图解](../assets/analysis/cover-detail-v2.svg)

字体名、品牌色号、网格数值和动态规则仍未核实，不从无文字的原作倒推官方排版规范。

## 十二维检查

- **intent / inferred**：从游戏时刻转成纪念碑式白雕塑；这是画面分析，创作方明示其重演标志性游戏瞬间。

- **identity / unverified**：未获得完整年度标志组合、留白与最小尺寸规范；应用拼图中的第三方标志不归为本风格。

- **typography / unverified**：原作主要为三维图像；无法从应用小图确认官方字体。案例中的深色无衬线是研究者补充。

- **color / observed**：W19-001/002/003：象牙白主体与亮灰环境，局部暖金属；岩底与背光面呈冷蓝紫，非纯白平涂。

- **layout / observed**：W19-002：中心主物体、两侧近大远小浮岛，顶部大弧状背景；W19-001是近景裁切，不能将对称中心构图固化。

- **graphics / inferred**：主物体—台座—整块悬岩形成上下关系；金属出现在边缘和部件。迁移的是关系，不临摹奖杯轮廓。

- **imagery / observed**：W19-001/003/005：角色统一为石质雕塑，细节和动作冻结；景深、尺度差、空气透视建立空间。

- **surface / observed**：主体相对完整，带接缝及轻微磨损；岛基有一块连贯主岩体，其大切面、层理和稀疏裂缝与周边少量散石分层。不是所有表面都光滑，也不是全体都粗糙。

- **information / unverified**：缺可读的高密度官方编排样本。导视及封面采用本次功能性补充，不能倒推官方网格。

- **motion / unverified**：项目页有视频链接，但本次没有观看视频本体，不推测节奏、镜头运动和转场。

- **applications / observed**：W19-004可见屏幕、采访背景与宣传载体沿用白雕塑；它是创作方的应用拼图，不保证每个画面由同一团队完成。

- **governance / inferred**：LostProject图像系统与腾讯区域红白帆船宣传、Phoenix封面、LV联名、比赛UI分开；完整规范与素材使用许可未知。

## 可执行规则与反证

### R-01

证据：W19-001, W19-002, W19-003，见 sources.json 对应原图及位置。

观察与转译：以象牙白雕塑和浅色环境构成整体明度，保留冷蓝紫背光与岩底反射；金色只占少量部件。

不变量：主次色彩职责。可变参数：冷暖强度与环境亮度。

反例：暗底、荧光赛博、大面积纯金会改换系统。

验证：缩小后仍可辨白主体、冷阴影、金属点，而非一团白或满屏金。

### R-02

证据：W19-002, W19-005，见 sources.json 对应原图及位置。

观察与转译：原创主物体位于有明确上下结构的悬浮岩基上，辅岛以尺度差退后；近景可只保留局部。

不变量：主物体—台座—一块连贯主岩体。可变参数：岛数、主物体、偏心与裁切。

反例：简单白色产品加金边而没有空间关系会退化为通用广告。

验证：去掉奖杯与角色仍看得到台座、断岩和悬浮空间。

### R-03

证据：W19-001, W19-002, W19-003，见 sources.json 对应原图及位置。

观察与转译：把完整雕塑的受控接缝和轻磨损，与主岩体的大切面与少量周边散石分开；金属是边缘或结构件，避免满幅金裂纹。

不变量：材质与构造层级。可变参数：磨损强度、金属位置。

反例：全部变成陶瓷花纹或破碎金缮将丢失层级。

验证：检查主体大面、岛基断面、金属连接是否分层。

### R-04

证据：W19-001, W19-002, W19-005，见 sources.json 对应原图及位置。

观察与转译：以冻结动作或原创有张力的体块建立纪念碑感，用近大远小、遮挡与轻雾表现尺度。

不变量：雕塑体量与空间。可变参数：题材、视角和焦深。

反例：必须靠原英雄或龙才成立，就没有完成迁移。

验证：更换植物、器物、建筑后仍有尺度层级与受光转折。

### R-05

证据：W19-001, W19-002，见 sources.json 对应原图及位置。

观察与转译：宽幅可借助大弧背景聚拢空间，竖幅沿上升轴组织；不要固定复制中心奖杯与两侧龙。

不变量：环境对主体的空间组织。可变参数：对齐轴与负空间。

反例：把原全景等比塞进所有版型不可算适配。

验证：横幅偏右主体、竖幅上升主体都保持环境和岩基关系。

### R-06

证据：W19-004, W19-002，见 sources.json 对应原图及位置。

观察与转译：按载体保留图像核心并删减细节：包装分正侧，服装胸小背大，导视功能字先读。此为分析者扩展。

不变量：跨载体可辨核心。可变参数：图像面积、细节密度、文字层级。

反例：同一海报贴六个样机不构成验证。

验证：看包装侧面、织物可印区域及导视箭头是否独立成立。

# Worlds 2019 迁移设计中的中外文搭配

这是研究者为新内容建立的文字适配，不是已核实的赛事官方字体规范。原作封面主视觉没有足够的字体系证据。

1. **匹配骨架与视觉重量。**本次迁移使用深石墨色、结构利落的无衬线。中文笔画多，用开放字腔、较轻一档的字重保持内部空隙；与英文比较实际黑白密度，不按相同字号/字重数值机械配对。不要默认粗宽方黑，也不要给中文加书法。
2. **宽窄由字形与编排完成。**英文章节标题可窄高，中文选择自然结构、略有纵向节奏的字形，并用断行和字面大小呼应；禁止横向硬压中文。字距分别设置：中文词组较紧，英文大写可稍疏，不把一套tracking全局套用。
3. **先确定语言主次。**中文受众可用中文作主标题、英文作较小的副标题；保留STRATA拉丁刊名字标不代表英文正文必须更大。两种语言共用对齐轴、分组、深灰色和留白秩序，可以有不同字号与行数。
4. **统一层级而不堆重复内容。**刊名、专题与封面线各有职责。长译文重新断行；小字号中文保证可读，导视先看目的地和箭头，服装双语简化到可印尺度。数字、标点与中外文基线做光学检查。
5. **验证并说明局限。**本次以“悬浮之境 / MONUMENTS IN AIR”检验中文主、英文辅。首轮中文过重，第二轮略减笔画，仍保持较强标题感；没有验证精确字体、字号或印刷。图中文字为模型位图，正式可编辑稿须用可授权字体单独排版。

其他原语言也按骨架、重量、节奏、对齐与语言职责匹配；不把本案例的黑体方向机械套到所有国际风格。

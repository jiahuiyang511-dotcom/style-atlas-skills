# 分支与物料核查

1. A：笔势起落与硬字块是否对照，小字是否稳定？
2. B：小弧线重复与大云气状轮廓是否同时成立，暗纹是否低于标题层、跨面连续？若只剩通用波浪或三角碎片应修订。暖金与青色配色允许独立于橙红笔刷分支。
3. C：城市或其他原创图像是否来自同一连续构图、仅在字形内展开？字间负空间、字腔、完整单词是否清楚？铺满背景再叠实色字不算通过。
4. 不用原人物、赛事徽记或口号证明风格成立。具体传统纹样名称、字体、官方色值和软件实现未核实时保留研究边界。
5. 必需文字与箭头逐项核对；中外文按所选分支处理字距、字腔、主次，不能机械压缩。
6. 物料分别检查包装转角、衣物印花位置、横幅裁切和导视层级。概念通过不代表制造或现场距离测试。
7. 系统覆盖与单图质量分开判断。只有实际出过并看过该分支的案例，才能标为已验证；不得把未用到的规则全挂到每例上。

8. 迁移审查：遮住标题名称后，新作品是否仍重复原作同类主体、视角、标识轮廓和摆位？若这些都接近，需要实质重选题材与品牌呈现，不能靠“原创重画”四字直接判通过。

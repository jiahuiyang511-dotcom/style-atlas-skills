# Worlds 2020 视觉转译

先确定物料、比例、品牌和必需文案。缺少非关键内容时可制作明确标为虚构的概念，不捏造真实产品承诺。此 Skill 的目标是制作实际设计；用户只要 Prompt 时再止于文字。

## 设计决策

读 [视觉规则](references/style-guide.md)，先按任务选主分支，而非默认所有画面都是青色笔刷：

- **A 笔势大字**：深蓝底、青色有起伏的原创笔势、橙红窄高重字；清晰小信息沿边缘对齐。
- **B 传统暗纹**：密集小弧线与大云气状有机轮廓共同铺底，深色底与蓝紫细线关系稳定，暖金窄字和青色小标居上。正侧面可连续。与尖角线图分开，具体传统纹样名未获官方确认；不要擅自命名或添加象征解释。
- **C 图像填字**：巨型窄高字本身构成图像窗口，一幅连续原创图像跨字形展开，字外、字间与字腔保留深色；品牌标识与小信息独立分级，标识可以转到边角、改成文字或按简报省略图标。城市、原角色和居中徽记位置都不是固定要求。主体题材与品牌形式先按新任务独立设计，不能只换名称或重画近似图标。不能用背景图上叠实色字冒充遮罩。

共同机制是字形、占幅、负空间和信息主次；橙红、青色笔刷与城市题材都不是三分支共同必需。不要等量混合全部母题。用户指定分支时优先执行；未指定时按载体和简报决定。批量案例若声称覆盖该系统，应让 B、C 也各有实际输出，不能六例都只使用 A。

中文按所选分支决定书法或清晰功能字；B 不强加毛笔，C 保留汉字字腔并单独验证。中英文分别处理字距、断行和视觉重量，不能机械压窄汉字。详见规则的双语边界。

## 制作

1. 根据简报选主母题，先定主标题、主体与小信息的阅读顺序。研究来源见 [sources.json](references/sources.json)；原图按链接查阅。书法、粗字与细线的作用和占幅比精确色号更重要。
2. 使用 [物料配置](references/material-profiles.json) 适配载体。包装分正侧面，衣服区分胸前与背面；导视让方向优先。不要把同一张海报贴满所有样机。
3. 需要生成图时，把 [自包含模板](references/image-prompt-template.txt) 所有变量替换为实际简报，选择可用图像工具生成并保存。原作只作为风格研究输入，不沿用其角色、标志和口号。需要可编辑稿时另行排版，明确位图与源文件的差别。
4. 逐张看实际结果，核对必需文字、方向、主次关系、载体和虚构信息。错字或方向问题先修订；记录真实轮次，不把结构检查当成视觉通过。

## 审查与交付

对照 [核查边界](references/evaluation.md)。交付实际文件、最终 Prompt、参考链接、修订及未验证项。生成文字不证明字体已授权，包装样机不等于刀模与生产验证。没有图像工具时明确案例未完成，不用原作或占位图冒充新案例。

# MSI 2023 视觉语法原创转译

完成实际设计；只要Prompt时交付自包含文本。先读 [视觉指南](references/style-guide.md) 与 [来源](references/sources.json)，按任务查看 assets/reference、assets/analysis。

1. 确定物料、尺寸、品牌/产品、逐字文案、场景与交付形式。缺少信息可用显式原创概念，性能、认证、价格和真实活动承诺不能补造。
2. 分必读信息与表现层。强红/米白/近黑可换底，几何重字建立品牌，一处签名式短语表达态度，极窄高字可用于专题。小字用等宽/中性无衬线，关键字保持完整。所有字体方向和色名为分析建议，未取得官方字体或色板规范。
3. 用分离斜节段或直边截断带形成方向；签名可跨图形，避开品名和日期。轻颗粒与水平扫描拖影只在表现边缘。不是红色爆炸、光谱液态边、绿圈撕纸或柔色方格。
4. 参考 [物料适配](references/adaptation.md)：包材正侧面、衣物安全区、横幅左右关系、导视方向和封面刊名分别处理。彩色摄影可保留肤色与材料；新内容不复制官方人物、赛事徽记、字标和四箭头标。
5. 选适合输出的工具制作：位图使用图像工具，可编辑稿按任务排版；输出场景效果与生产展开图需区分。独立模型模板见 [master.txt](references/master.txt)，完整提示词无需读取网站或本Skill。
6. 按 [审查](references/evaluation.md) 实看文字、图形关系和承载物，记录参考、实际提示词、轮次与修改，针对观察到的缺陷修订。交付实际图/文件、Prompt和未验证边界。

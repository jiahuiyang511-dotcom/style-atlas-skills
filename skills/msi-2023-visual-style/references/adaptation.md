# 物料取舍

活动海报：区分完整几何品牌、手写短语和极窄高专题；斜带作背景，三行日程在高对比净区稳定对齐。

产品包装：正面完整品名优先，侧面延续斜向节段；一处手写不盖功能字，颗粒只在印刷图层，折线和接缝保持可信。

电商横幅：宽幅分文案/产品两区，斜带横向连接；缩短手写短语并保品牌完整，产品轮廓和小字净区不被拖影遮盖。

服装印花：前胸小几何字，后背可用原创几何图与手写叠层，斜节段放在安全印区；不复制徽记，不跨领口、袖口与结构缝。

活动导视：目的地与箭头最大且完整，删除交叉手写与装饰微字；红米白黑建立高对比，仅边缘保斜带与轻纹理。

刊物封面：刊名与期号完整；原创人物/物件摄影可用矩形拼版，手写专题与几何识别分层，底栏稳定，不伪造真实刊号条码。

其他：先把必读信息放净区，再安排红米白黑、几何重字、一处签名笔迹与斜向节段；按承载物减少纹理和微字。

包装与横幅如非相同SKU应显式区分；衣物两个视图完整入镜；效果图不是展开图。

# Worlds 2021 灰白浮雕主美术

本Skill的目标是灰白浮雕主美术。服装原系列、场馆、赛程和主题曲只作旁证，不把所有分支平均混入新设计。

先确认物料、画幅、主题和必需文案；低风险概念可以注明假设后继续制作。参阅 [八点分析与证据](references/style-guide.md)，选取实际主美术原图作为风格参考。

## 从分析推导设计

1. 建立原创中心圆章或结构核心，以多层环框、面板和少数外放构件组成同一装置。
2. 区分前景完整有机体积、中景厚板框架、后景浅纹三档起伏；避免全变等高线切层。
3. 保留硬边倒角与连续有机曲面的对照，题材可换植物或器物，不依赖原赛事角色。
4. 纹样附着后层分面，反差与起伏低于主体；几何细纹、有机曲线分别归位。
5. 用光滑灰白、统一柔光、遮挡与接触阴影显形；不靠多色、铬镜面或裂石制造层次。
6. 电蓝多面晶体只是集中小焦点；不要用大蓝色块替代浮雕。
7. 围绕中心组织曲线／斜向动势，外围可出血，中央焦点保住；横竖画幅重新组织。
8. 重要短标题可做同材质实体字，中文保持自然比例与准确笔画；功能小字仍须高对比可读。

## 制作与验证

先安排主体、结构、浅纹、光线、蓝晶体和文字的职责，再实际出图或排版。读 [物料配置](references/material-profiles.json) 作承载物取舍，使用 [自包含Prompt](references/image-prompt-template.txt) 时替换全部变量。

对照原图检查：去掉赛事身份后是否仍像同一套主美术；是否只有白色加蓝点却没有体积与扣合；是否被黑蓝大字板抢走主次；是否出现粗糙石山或漂浮岛；文字、箭头及产品信息是否准确。针对实际缺陷修订，不能用旧图或程序图解冒充新生成案例。

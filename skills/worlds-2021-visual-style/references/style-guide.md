# Worlds 2021 灰白浮雕主美术研究

本次按用户最新范围重做：只学习灰白浮雕主美术，其他服装、场馆、信息图和叙事插画保留为次级参考。不是对整届视觉分支进行平均学习。

主证据为 W21-001 官方原作完整近景、创作方带实体大字的宽幅画面。以下先写原图可见观察，再写研究者归纳及制作建议；不声称掌握官方建模文件、字体、着色器、灯位或数值规范。

相较上一版，关键修正是：不能只把它理解成“等高线白雕＋一个蓝方块”，也不能让赛程的黑蓝字块成为成图主体。真正需要迁移的是中心组织、不同起伏尺度、有机体积与硬边结构、浅纹、同色光影、少量蓝晶面及实体字的共同关系。原角色与Worlds徽记属于身份资产，换内容后依然要保住上述关系。

## M-01 中心圆章与放射外框

原作观察：中心标识嵌入多重圆环，外侧尖形向四周放射；动物绕环而非各自漂浮。

证据：W21-005，像素区域 [360, 180, 1250, 850]，https://studiojung.co/#worlds21 。

机制／不变量（研究归纳）：圆形先稳定视线，尖角与绕行动势提供张力；主体构成同一装置。

制作规则：先建原创中心圆章与少数外放结构，再接枝叶或机械件；不要照搬Worlds徽记。

可变量：圆环数量、倾角、外放方向可随画幅变化；并非每张都要四向严格对称。

反例：把白色物件分散摆在空中、只放一个孤立白塑像，失去组织关系。

验证任务：海报和横幅去掉原赛事名后，仍能看出中心、外围与放射秩序。

## M-02 前中后三档起伏

原作观察：前景动物身体有完整体积，中景徽记与环框为厚板，后景花纹近于浅刻。

证据：W21-001，像素区域 [0, 0, 1080, 900]，https://lolesports.com/en-US/news/worlds-2021-primer 。

机制／不变量（研究归纳）：深度存在层级：体积主体、结构板件、背景浅纹，而非等高压纹。

制作规则：分配高、中、浅三档相对起伏；前景可越过环框，细纹留在后层。

可变量：起伏幅度和遮挡数量按画幅与媒介减繁；数值不是已知官方深度。

反例：所有线条同样凸起，或只有等高线切层，会变成普通纸雕／地形模型。

验证任务：包装和封面缩小后仍能辨认主体、框架、细纹三种尺度。

## M-03 硬边倒角包住柔性曲面

原作观察：徽记与框架有连续硬边和倒角；周围身体、鬃毛与羽翼则是有机曲面。

证据：W21-001，像素区域 [410, 170, 1170, 900]，https://lolesports.com/en-US/news/worlds-2021-primer 。

机制／不变量（研究归纳）：机械式清晰边界与生命形态的曲面互相衬托，塑造精工而有动势的雕刻。

制作规则：把原创叶片、种荚、羽翼等柔性体积连接到硬质轮廓；倒角要干净。

可变量：有机与几何的比例可变；植物、器物均可替代，非必须动物。

反例：全做软黏土会失去利落边界；全做尖刺硬块则失去柔性对照。

验证任务：海报与封面同时保有一处明确的硬边和一处连续柔性曲面。

## M-04 几何刻纹与有机浅纹分工

原作观察：三角分区里有细密几何底纹与有机卷纹；它们服从面板边界，不盖住主轮廓。

证据：W21-001，像素区域 [1010, 0, 1600, 640]，https://lolesports.com/en-US/news/worlds-2021-primer 。

机制／不变量（研究归纳）：纹样是低优先的表皮信息；结构分面先成立，纹理随后归位。

制作规则：几何面用细重复纹，有机面用浅曲线；纹理的起伏与反差低于主体。

可变量：局部纹样、密度与区域可变；织物印图需减低频噪点，保留可读轮廓。

反例：满版浮雕花纹同样抢眼，或把摄影噪点当设计纹样，会让主体消失。

验证任务：近看见细纹，缩成缩略图先见主轮廓，印花和包装均能保主次。

## M-05 灰白表面靠明暗建立体积

原作观察：大部分物体同为灰白；明暗沿曲面过渡，接缝和遮挡处变深，没有满身金属反射。

证据：W21-001，像素区域 [0, 30, 780, 850]，https://lolesports.com/en-US/news/worlds-2021-primer 。

机制／不变量（研究归纳）：靠面向、遮挡与接触阴影分层；不是用多种颜色区分对象。

制作规则：用偏漫反射的光滑灰白表面，统一宽柔主光，保留窄接触阴影与亮面细节。

可变量：可小幅调亮度和阴影深浅；材质名仅是复现建议，官方着色器与灯位未知。

反例：镜面铬、通体玻璃、脏污裂石或均匀无影白面，都偏离原作灰白关系。

验证任务：横幅白底不丢轮廓；封面阴影足够显形而不变成大面积黑块。

## M-06 小蓝晶面成为视觉锚点

原作观察：蓝色集中在徽记下部的六边形多面晶体；周围仍是大面积灰白结构。

证据：W21-001，像素区域 [520, 300, 1090, 850]，https://lolesports.com/en-US/news/worlds-2021-primer 。

机制／不变量（研究归纳）：色彩对比集中，晶面冷亮与灰白哑光形成两重反差；小面积也足够醒目。

制作规则：给原创主物设置一个小而明确的电蓝多面嵌件；其位置依构图重心决定。

可变量：嵌件可在次焦点或少数呼应处；蓝色面积建议从小测试，不冒充官方占比。

反例：大蓝标题块压过雕塑，或全主体被蓝光染色，会把主美术变成另一套信息设计。

验证任务：六例缩小时先读到灰白体积，再被少量蓝引导；不要主要靠大蓝色块认风格。

## M-07 环绕动势与近景出血

原作观察：动物身体和圆环形成交错斜向；近景裁掉部分边缘，中央识别仍完整。

证据：W21-001，像素区域 [0, 0, 1600, 900]，https://lolesports.com/en-US/news/worlds-2021-primer 。

机制／不变量（研究归纳）：中心可辨与外围越界并存；裁切放大尺度，交叠让静态浮雕显得在运动。

制作规则：围绕中心组织一条清楚的曲线或斜向动势；裁外围，不裁掉唯一视觉焦点。

可变量：横幅可沿长边延展，竖幅改上下穿插；不是对旧画面直接拉伸。

反例：全景小物件居中、四周空白过多会变陈列照；随机裁切则失去中心。

验证任务：宽横幅与竖海报构图不同，但都有焦点、交叠和一条明确动势。

## M-08 文字进入同一个雕刻世界

原作观察：WORLDS 2021 与 MAKE/BREAK 是白色挤出字，有厚度和投影，与圆章共用表面光色。

证据：W21-005，像素区域 [0, 0, 1700, 330]，https://studiojung.co/#worlds21 。

机制／不变量（研究归纳）：大字本身成为空间结构，而非另贴的强色标题板；辅助信息才退为平面文字。

制作规则：重要短标题可做灰白实体挤出字；中文保持自然字形，按视觉重量配对，功能小字独立可读。

可变量：可采用刻入、凸起或局部裁切；功能文字不必全部白色三维化。

反例：全用大蓝底白字，或把所有细字做成浮雕，会分别抢走主美术或损害阅读。

验证任务：中文海报与封面检查实体字的厚度、光向和与主体的层次；文字须逐字准确。


## 十二维覆盖与未知项

意图为成败张力的研究归纳；标识只借中心组织而不复制原徽记；字体重点是实体字与空间关系；颜色重点是灰白体积与少量蓝晶面；布局见M-01、M-07；图形见M-03；图像与材质见M-02、M-05；浅纹见M-04；功能信息需独立可读，不以赛程模块作本轮主要语法。应用只验证核心关系如何适配六类物料。动态未连续观看，保持未核实。具体光照数值、精确材质、字体文件及生产工艺未核实。

## 中文与英文

中文版按自然字面宽度与视觉重量组织，避免把中文压成拉丁窄字。短中文主标题可作为灰白实体字，与主体共用光向、倒角和阴影；英文可更窄，按内容缩小配对。小字和方向信息保持高对比平面排字。这是研究适配，不冒充官方中文规范。

## 案例通过标准

检查灰白浮雕是否在画面中占主导，三档起伏与有机体积是否可辨，浅纹是否服从主轮廓，光向是否一致，蓝晶面是否少量聚焦，文字是否准确，是否摆脱原徽记与角色。包装和服装是概念表现，不等于制造打样；导视真实观看距离未测试。
